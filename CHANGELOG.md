# Changelog

## 1.0.0 (2026-10-20)

First release.

- Spreadsheet editor for any collection, with keyboard navigation, range selection, copy and paste with Excel and Google Sheets, and a fill handle.
- Editors for text, numbers, dates, toggles, options, and pickers for entries, terms, users and assets.
- Find and replace, CSV export and import, undo and redo.
- Changes are saved through each entry's blueprint validation, fieldtype processing, revisions and permissions, with errors shown on the cell.
- Multi-site support, *Edit in Spreadsheet* bulk action, *Use the spreadsheet* permission.
